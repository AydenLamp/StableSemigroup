## Branch commands

Use these commands from the repository root:

```bash
git fetch origin # updates local view of branches without changing files
git checkout main # switches working directory to the branch `main`
git pull # applies latest commits to the current branch

git checkout legacy #switches working directory to the branch `legacy`
```
